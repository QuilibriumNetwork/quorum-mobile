**2026-07-27: mobile bumped `@quilibrium/quorum-shared` to `2.1.0-37`** (committed directly to master, already-verified/published). This unblocked three previously-blocked tasks — confirmed by grepping the installed dist, not just trusting the version bump: **sync-all-conversation-settings** (typed part; PRs #63+#65 helpers present), **translate→IconLanguage icon swap** (mapping present), and **mobile adopt typed global-identity fields** (PR #57 fields present on `UpdateProfileMessage`). The first **shipped the same day as PR #185**; the other two are 🟢 ready below.

**2026-07-27: config sync had never published from mobile — PR #184.** `encryptConfig` imported `randomBytes` from `@noble/ciphers/webcrypto.js`, but v2 moved it to `utils.js`. The old subpath still resolves, so the binding landed as `undefined` and threw on every config write; `saveConfig` caught it, logged, and still saved locally. So the app looked healthy while **nothing** left the device — mute, blocked users, notification mute, bookmarks, space keys. Inbound was unaffected (`decryptConfig` reads the IV from the blob), which is why desktop→mobile appeared to work while mobile→anywhere silently did not. Found only because a new feature called `saveConfig` from a fresh code path. **Any cross-device sync behaviour observed on mobile before this date should be re-verified.**
